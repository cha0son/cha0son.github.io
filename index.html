每日饮食推荐系统

个人项目 · Java · 2026.10

一个加权打分 + 时间衰减的推荐引擎。解决的核心问题是「怎么让推荐既符合口味、 又不重复」。不是套壳调包，打分公式、衰减模型、评估脚本都是自己设计实现的。

  • 设计打分模型 score = α·偏好分 + β·时间分 + γ·场景分 − 惩罚分 + 噪声，各项权重可配置
  • 用 1 − exp(−Δt/λ) 建模「想念程度」回升曲线，并按菜系个性化半衰期 λ
  • 实现候选池自适应：过滤条件导致候选集为空时逐级放宽，而不是直接报错
  • 做消融实验验证时间衰减的贡献：β=0.30 时两菜分差 0.091，β=0 时完全持平
  • 自建 82 道菜品库，前端提供打分、历史、参数实时调节
